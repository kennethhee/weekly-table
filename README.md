# Weekly Table & Kitchen Journal

A high-protein, anti-inflammatory meal planner, dual-supermarket split-shopper, and low-friction Sunday batch prep companion for a household of two.

## Features
- **Dynamic Meal Options:** Rotate across 12 targeted recipes designed for cellular anti-inflammation, liver clearance, and 44g+ protein.
- **7-Day Calendar Spread:** Monday–Sunday visual planner with kitchen rhythm milestones.
- **Dual Supermarket Split Checklist:** Real-time unit-price comparison (`$/kg`, `$/100g`, `$/100 sheets`) between Woolworths and Coles with aisle filters.
- **Direct-in-Glass Oven Bake:** Step-by-step instructions for zero-pan meal prep.
- **Standalone PWA Support:** Add to iPhone Home Screen for a clean, full-screen mobile experience.
